Roster

Spoken names are extra words the microphone might hear for a player, separated by commas, for example “Shaq, Larry S”. A jersey number lets you call “number 10”.

HVP points

Same values as the Scoring Key in the workbook. Steals, blocks and offensive rebounds earn their points automatically.

Options

Short share links

Lets the app save shared sessions into your GitHub repository by itself, so “Create short link” is one click. Needs a GitHub access key that can only change this one repository. The key stays in this browser; it is never put in the page, in backups or in share links.

Without a key, “Create short link” downloads a small file instead; you put it in the s folder of your heatfilmcaller repository and Commit and Push in GitHub Desktop.

Backup

Everything is saved in this browser. Download a backup to move it to another computer or keep a copy.

The shape of a call

Say the player, then what happened, in plain basketball language. Add a colour in a scrimmage if you want to; the squad is usually known from the player. Add a time only when the play happened earlier than where the video is now.
